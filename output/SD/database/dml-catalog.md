# SweetCommerce Critical DML and Query Catalog

Draft 0.1. All parameters are bound. TX identifiers refer to the [transaction matrix](transaction-concurrency-matrix.md). Every customer entity read uses the authenticated account, never a supplied account ID. Scoped missing resources return NOT_FOUND.

Representative SQL for last-unit allocation runs only inside TX-04/05 after the ordered day lock and per-product checks. Zero rows means capacity unavailable.

    UPDATE capacity_day
       SET allocated_units = allocated_units + :requested_units,
           version = version + 1
     WHERE service_date = :service_date AND NOT closed
       AND allocated_units <= max_units - :requested_units
    RETURNING service_date, version;

Reporting converts inclusive local dates to UTC [from, next day after to). Restrict user-supplied filter dimensions to the contract enumeration before building a bound query.
